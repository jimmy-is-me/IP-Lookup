GOOD TO KNOW

使用前請留意

  • IP 查詢結果由第三方資料庫提供，資訊可能不完整或有誤差。
  • 查詢時，輸入的 IP 與您的連線 IP 會傳送給 ipwho.is 與 ipapi.co；查詢自己的 IP 時也會連線至 ipify。
  • 分享查詢連結會將 IP 放在網址中，請確認適合公開分享。
